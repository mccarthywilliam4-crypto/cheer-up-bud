# 😒 Cheer Up, Bud

A mobile browser-based joke game. Try to cheer up your impossibly grumpy friend. Nothing works. Everything makes him angrier.

## Play
https://mccarthywilliam4-crypto.github.io/cheer-up-bud

## How To Play
- Pick items from the grid to give to your grumpy friend
- Survive all 7 themed rounds
- If his anger maxes out, pass the Beer Bong Challenge to reset it
- Make it through all rounds to earn: *"...I guess you're ok."*

## Rounds
1. 🏒 Hockey
2. 🦌 Hunting
3. 🏕️ Camping
4. 🚗 Cars
5. 🌿 Weed
6. 🎣 Fishing
7. 🍺 Bar Crawl

## Adding Assets
- Drop face photos into `assets/face/` named: `annoyed.png`, `angry.png`, `fuming.png`, `volcanic.png`
- Drop item images into `assets/items/` — filenames match those in `game.js`
- Until images are added, illustrated SVG placeholders display automatically

## Tech
- Pure HTML/CSS/JavaScript — no dependencies
- Hosted free on GitHub Pages
